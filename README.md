### 🎓 AI Exam Portal — Multi-Agent System
[![Repo](https://img.shields.io/badge/View_Repo-0D1117?style=for-the-badge&logo=github&logoColor=white)](https://github.com/SiddarthaKaleru/AI-Exam-Portal)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

</div>

> An AI-powered exam platform orchestrated by a **7-agent LangGraph pipeline**. Admins upload PDFs; the system auto-generates MCQs, short & long answers, conducts exams, evaluates responses using LLMs, and produces detailed analytics — all with anti-cheating built in.

| Agent | Role |
|-------|------|
| 🧠 Content Agent | PDF parsing → FAISS vector indexing → topic extraction |
| 📝 Question Agent | MCQ + Subjective generation at Easy/Medium/Hard |
| 🏗️ Builder Agent | Dynamic exam config JSON for React frontend |
| 📋 Manager Agent | Unique 6-char codes, timers, session state |
| ✅ Evaluation Agent | MCQ scoring + LLM-based semantic grading |
| 🛡️ Anti-Cheat Agent | Tab-switch detection, copy-paste blocking |
| 📊 Analytics Agent | Score distributions, topic-wise rankings |

**Stack:** `Python` `FastAPI` `LangGraph` `FAISS` `React` `MongoDB` `JWT` `Tailwind CSS`

### 🧭 Career Co-Pilot — AI Resume Analyzer
[![Repo](https://img.shields.io/badge/View_Repo-0D1117?style=for-the-badge&logo=github&logoColor=white)](https://github.com/SiddarthaKaleru/Career-Co-Pilot)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

</div>

> A **multi-agent CrewAI system** that deploys 4 specialized AI agents to analyze your resume against a job description. Get an instant **ATS match score**, detailed strengths/weaknesses breakdown, and actionable improvement advice — all powered by Groq's lightning-fast LLM API.

| Agent | Role |
|-------|------|
| 📄 Data Extractor | Parses resume PDF → structured markdown |
| 🎯 ATS Analyst | Calculates match percentage & rationale |
| 🔍 Resume Screener | Qualitative fit analysis & suggestions |
| 📑 Report Compiler | Synthesizes all agents into a final report |

**Stack:** `Python` `CrewAI` `Groq API` `Streamlit` `PyMuPDF` `LangChain`
